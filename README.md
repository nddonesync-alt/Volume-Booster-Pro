# 🔊 Volume Booster Pro

> Boost your browser audio up to **800%** with built-in equalizer profiles, and lightning-fast hotkeys. 100% Free and No Ads
---

## ✨ Features

- 🚀 **Up to 800% Volume Boost**
- 🎛️ **Pro Equalizer Profiles** — (*Default*, *Voice Clarity*, *Bass Boost*).
- ⚡ **Manifest V3 Architecture** — Lightweight, privacy-focused, and battery efficient using Web Audio API.
- 🛡️ **Free 100%** — No ads.
---

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `0` – `8` | Set volume instantly from **0% to 800%** |
| `V` | Cycle through Equalizer Profiles *(customizable in Settings)* |
| `R` | Reset volume to **100%** and Profile to **Default** |
| `↑` / `→` | Step volume up |
| `↓` / `←` | Step volume down |

---

## 🛠️ Installation (Developer Mode)

1. Clone or download this repository.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the extension directory.
5. Enjoy enhanced audio across all your favorite tabs!
